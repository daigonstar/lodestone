Compatibility (Proton)

      
Checking…

      
      
Windows games and launchers (Battle.net, Guild Wars 2, games you add) run through Proton using umu-launcher, which Lodestone keeps in its own folder. Steam isn't needed.

      

      
Library

      
      
When you own a game on several stores, Lodestone shows the installed copy, or else the first store in this order. Use the arrows to change it.

      

      
      
Without a key, Lodestone guesses your Steam library from Steam's local files, which also keep games you refunded. With your own free key (steamcommunity.com/dev/apikey, any domain name works) it uses Steam's exact owned-games list. Your profile's Game details must be Public for Steam to answer.

      
Steam

      
      
Artwork

      
      
Without a key, Lodestone finds artwork from Steam's store. A free SteamGridDB key (steamgriddb.com → Preferences → API) adds thousands of community covers and banners, including for games that aren't on Steam.

      
Emulation

      
      

      
Lodestone looks for EmuDeck's layout (Emulation/roms/<system>) in your home folder, RetroDECK's folder and on mounted drives. If your ROMs are somewhere else, choose the Emulation folder, its roms folder, or any folder with one folder per system (snes, gba, psx…). Starting from scratch? Create folders makes that layout in the folder above (or ~/Emulation), with a folder for every system Lodestone knows; put each system's ROMs in its folder and Rescan. Nothing existing is changed.

      
RetroAchievements

      

        
        
      

      
For your ROMs: proper names, box art and details from RetroAchievements, and each game's achievements with your progress. Get the key from your RetroAchievements settings → Keys. Lodestone matches ROMs to RA on your PC (no ROM or fingerprint is sent) and only sends your username and key to RA. Your progress counts when you play with achievements turned on in the emulator (RetroArch: Settings → Achievements).

What's already on this PC

        
Lodestone reads these launchers' libraries directly. Nothing needs to be imported.

        

      


      

        

        
Your store launchers

        
Lodestone starts your games through each store's own launcher. Install the ones you use: Lodestone installs them with winget, Windows' own package manager, from each store's official download. Installing accepts the launcher's licence, as installing it yourself would.

        

        

        

        
Windows games (Proton)

        
Epic, GOG, Battle.net and Windows games you add run through Proton, the same compatibility layer Steam uses. Lodestone keeps its own runner (umu-launcher), so Steam isn't needed for these.

        

          
Checking…

          
          
"Automatic" uses the newest GE-Proton on this PC, or downloads one the first time a game needs it.
